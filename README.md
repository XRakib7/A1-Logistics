# 🚚 A1 Logistics  
### Modern Logistics & Parcel Management Platform

**A1 Logistics** is a powerful, feature-rich Android application built for **Admins** and **Merchants**, offering **real-time parcel tracking, advanced analytics, revenue insights**, and a **highly polished modern UI** designed for productivity and scale.

## ✨ Key Features

### 🧑‍💼 Role-Based Access Control
- **Admin Dashboard**
  - Full system control and monitoring
  - View all merchants, parcels, and total revenue
  - Advanced analytics with merchant-wise insights
- **Merchant Dashboard**
  - Parcel & order management
  - Revenue, success rate, and performance tracking
- **Secure Authentication**
  - Firebase Authentication
  - Role-based access (Admin / Merchant)
  - Hidden admin signup for enhanced security

### 📦 Package & Order Management
- **Unique Package ID System**
  - Format: `A1-M001-0001`, `A1-M001-0002`, etc.
- **User ID Convention**
  - Merchants: `M001`, `M002`, …
  - Admins: `A001`, `A002`, …
- **Real-Time Status Tracking**
  - Full status history in chronological order
- **Advanced Filtering**
  - Filter parcels by status, date, or last update
- **Excel Export**
  - Export single or bulk parcel data
  - Powered by **Apache POI**

### 📦 Install APK (Recommended for Quick Use)

1. Download the latest APK from the **Releases** section  
   👉 `GitHub → Releases → app-release.apk`

2. Copy the APK to your Android device (or download directly on the phone).

3. On your device:
   - Go to **Settings → Security**
   - Enable **Install unknown apps** (Allow from this source)

4. Tap the APK file and install the app.

5. Launch **A1 Logistics** 🚀
